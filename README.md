# ForgeFit — Complete Figma Replica

Six-screen React/Vite implementation based on the six top-level Figma frames at 1440 × 1024.

## Screens

- Dashboard
- AI Pose Coach
- Equipment Scanner / Workout Generator
- Exercises Library
- Progress & Body Metrics
- Post-workout Analysis

## Run locally

```bash
npm install --cache .npm-cache
npm run dev
```

Use the left sidebar in each screen, or hover the page switcher in the lower-right corner. Production build: `npm run build`.
